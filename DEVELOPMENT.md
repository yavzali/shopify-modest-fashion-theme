# Shopify Development Workflow

## Quick Commands

### Development (Hot Reload)
shopify theme dev

### Deploy to Live (Only when ready!)
# Always commit first
git add .
git commit -m "Description of changes"
git push origin main

# Then deploy
shopify theme push

### Pull from Live Theme
shopify theme pull
